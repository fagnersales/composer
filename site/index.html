01 / How it works

One prompt in. Real options out.

Run /composer in any project. The rest happens on the board — no chat round-trips.

01

Ask for variants

/composer explore checkout layouts — the fleet fans out, one headless agent per direction, each briefed to diverge for real: layout, structure, flow — not a color swap.

02

Cards land live

Each variant appears on the infinite board the moment its file lands — clickable, inspectable, with lineage edges from parent to child. Ghost cards show what's still building.

03

Iterate from favorites

Select a card and type — children build under it. Shift-click several to combine them into one. The Tweak toggle makes one small change inline, in seconds.

04

Pick, then implement

“Pick this one” crowns the winner and hands you a copy-paste brief for a fresh agent session — with the exact file (or commit SHA) to implement from.

02 / Modes

From napkin sketch to real code.

Pick fidelity per task. All three run backend-free — the board never depends on a live server to show a card.

sketch

Static comps, fastest

No interactivity — the whole budget goes to visual quality. The quickest way to compare five directions before committing to any.

html · default

Interactive mockups

Self-contained HTML with inline CSS/JS and in-memory state — buttons work, lists mutate, nothing touches a backend. A demo of a direction, not a product.

worktreefor existing apps

Fork the real code

Builders work in git worktrees of your actual app, commit their change, and ship a screenshot or recording as the card. No mockup drift — and picking a winner means cherry-pick this SHA, not “rebuild it”. Your branches, index, and working tree are never touched.

03 / The board

A design space, not a chat log.

Lineage you can see

Every iteration draws an edge from parent to child; combines keep a strand to every parent. One key tidies the whole tree into generations.

Phone remote

Scan one QR and your phone becomes a synced second screen — swipe variants there, the board follows here, and task switches follow both ways.

Model per request

Choose sonnet, opus, or fable for each iterate right on the board — cheap drafts, heavyweight refinements, your call per branch.

Reference images

Paste or drop screenshots into the input — they ride along to the builders as visual guidance for the next generation.

Yours, locally

The hub runs on localhost; variants live in each project's gitignored .composer/ folder — an accumulating, browsable generation history.

No click goes unheard

The fleet agent heartbeats while it listens; if it's gone, the board locks iterate and says so — requests can't silently pile up.

04 / Install

One prompt. Your agent does the rest.

Paste the install prompt into Claude Code or Codex — it clones the repo, wires the /composer command into your agent (it asks which), and verifies the board end-to-end. Requires Node 18+ and the Claude Code CLI (the builder engine).
